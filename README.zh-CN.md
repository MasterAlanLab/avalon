Avalon 是一款面向移动端和桌面的代理客户端，让你集中管理订阅、节点与代理链，查看连接状态，并备份本机配置。本地功能全部免费。

## 获取 Avalon

[官方网站](https://getavalon.app)

Avalon V2 正在开发中，暂未提供 V2 下载。现有发行仍为 V1；旧版源码与下载入口见 [V1 归档](https://github.com/MasterAlanLab/avalon/tree/legacy/v1)。

## 功能

- **订阅与节点**：通过链接、文件或二维码导入，管理订阅、更新内容及编辑独立节点。
- **代理链**：将多个节点组合为连接路径，并测试节点或整条链路的延迟。
- **灵活路由**：在规则、全局与直连模式之间切换。
- **连接信息**：查看连接、日志、流量、延迟和出口 IP。
- **本地数据与备份**：配置保存在本机，代理凭据加密存储，支持密码保护的备份与恢复。
- **外观与语言**：提供浅色、深色外观，以及简体中文和英文界面。

## 平台

面向 Android、iOS、macOS、Windows 和 Linux，各平台的功能可用范围有所不同。
