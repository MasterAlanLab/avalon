# Avalon 产品规格

本文件是用户可见行为的唯一来源：页面、控件、默认值、操作结果和平台差异。视觉令牌、组件尺寸与动效规格由 [UI_DESIGN_SYSTEM](UI_DESIGN_SYSTEM.md) 维护，已确认的取舍见 [DECISIONS](DECISIONS.md)。应用中的账号、节点、IP、统计、设备和版本均使用真实数据。

## 1. 产品原则

1. **本地优先**：本机数据库是事实源。启动、编辑、连接都不依赖网络或 Cloud；本地功能全部免费。
2. **操作即生效**：选择配置、选择节点、切换模式、修改设置后立即保存；普通代理运行中则自动生效（D10）。没有「应用」按钮。
3. **只显示真实结果**：「已连接」「已同步」等状态以宿主或服务端确认为准。统计、延迟、出口 IP、用量都是实测值，未知显示「—」。
4. **失败不静默降级**：不自动改为直连，不悄悄换节点，不删除用户设置来让启动通过。错误显示在触发它的页面。
5. **文案直接描述功能（D113）**：中英文功能介绍、设置说明和操作提示简短正向，说明功能、结果或下一步，省去多余的否定式解释及实现、研发验收细节。真实状态、错误原因、备份来源范围、永久删除和订阅续费等重要后果保持准确。

**项目支持范围与说明（D102）**：Avalon 不支持在中国大陆地区使用。项目根 README 默认英文，提供简体中文版本，并在两个版本顶部显著说明使用者自行承担其行为及后果、遵守适用法律，以及适用法律允许范围内的无担保和责任限制。对应说明见 [许可与发行](LICENSING.md#6-使用范围与免责声明d102)，AGPL 授权保持不变；本项为项目文档与支持政策。

## 2. 导航

- **移动端**：底部四个标签：仪表盘、代理、配置、工具。工具页分组如下：
  - 设置：登录与同步、基础设置、高级设置、分应用代理、GEO 规则集、Tailscale
  - 查看：连接、日志
  - 最后独立一组：关于 Avalon

  上述分组顺序按 D101；「登录与同步」进入 Cloud 页，固定为设置第一行，Cloud 未开放的构建隐藏此项。iOS 隐藏分应用代理（D22）。

  添加订阅、节点、链使用底部弹层；子页面有返回按钮。
- **桌面端**（macOS、Windows、Linux）：
  - 左侧栏放四个入口，底部是账号行（进入 Cloud）。
  - 顶部工具栏：页面标题；代理页另有「测速」，配置页另有「全部更新」「添加」；所有页面右侧都有出站模式分段和状态／启停按钮。
  - 工具页采用左列表、右内容的布局；左列表同样按设置、查看、关于 Avalon 排列，「登录与同步」位于设置第一行（D101），默认右侧仍显示基础设置。
  - 添加使用对话框，可点遮罩关闭。

## 3. 页面与操作

### 3.1 仪表盘

| 区域 | 行为 |
| --- | --- |
| 状态区 | 未连接：显示「Avalon」和「sing-box ‹版本› 已就绪」；已连接：显示连接时长 `HH:MM:SS` 和「‹模式›模式 · ‹当前出口›」，直连模式下出口为 DIRECT |
| 启停按钮 | 启动或停止普通代理。没有选中配置时，提示「请先添加配置」并跳到配置页。已连接时按钮保持强调色与静态阴影，不播放循环波纹（D99）；保留按压反馈与连接状态颜色过渡 |
| 出站模式 | 规则／全局／直连分段 |
| 网络速度 | 实时 ↑↓ 速度，最近 30 秒曲线；今日上传／下载（宿主后台按本地日期累计，见 [RUNTIME_HOST §6](RUNTIME_HOST.md#6-观察)） |
| 当前节点卡 | 当前配置主选择组的实际出口：名称、协议、延迟。点击进入代理页 |
| 出口 IP 卡 | 位置和 IP。连接后经当前出口探测，未连接时显示本机出口，失败显示「—」 |
| TUN／系统代理开关 | 见 [§6](#6-平台差异d22) |
| 标题栏 Cloud 图标 | 未登录或免费：cloud_off；同步中：cloud_sync；已同步：cloud_done。点击进入 Cloud 页 |

**手机布局**（D92）：为单手操作，自上而下为大标题、当前节点卡与出口 IP 卡、网络速度、出站模式、TUN 与系统代理、状态区与启停按钮（启停按钮在最下方的拇指区）。网络速度卡占用剩余高度；屏幕太矮时整页滚动，曲线取固定高度。桌面为四列网格，与 V3 一致，「今日流量」卡显示宿主报告的当日上传／下载。

**连接状态的显示**：

- 状态一行：未连接、正在连接…、已连接（绿色，圆点闪烁）、正在重新连接（重载即重启内核，D82）、正在断开…。
- 标题：已连接时是本次会话的时长「时:分:秒」，重新打开应用后接着走；否则是「Avalon」。
- 副标题：已连接时是「规则模式 · 当前出口」；未连接时是「sing-box 版本 已就绪」；本平台的宿主尚未提供时是「内核未接入」；上一次启动失败时以红色显示一句原因。
- 启动失败时另弹一次说明，带上编译器或内核给出的细节。原因有：需要 VPN 授权、未选配置、配置尚未下载、无法生成配置、无法连接到 Avalon 服务、端口被占用、内核不接受这份配置、内核启动失败、服务没有及时响应。失败后保持未连接，不改为直连，不自动换节点。
- 网络速度与曲线每秒更新；今日上传／下载从本机当日零点起跨会话累计，未知时显示「—」。
- 宿主自行停止（用户在系统设置里关掉 VPN、被别的 VPN 顶替）时，页面随之回到未连接，不自动重连。

### 3.2 代理

- **组标签**：当前配置的组按导入顺序排列，「自定义」固定在第 2 位。组头显示「类型 · N 个节点 · 当前成员」。
- **成员行**：名称、协议、延迟、选中标记。
  - 延迟颜色：<150 ms 绿色，<300 ms 橙色，其余红色。
  - 超时显示红色「超时」，其他失败（连接被拒、握手失败等）显示红色「失败」，未测显示「—」，测速中显示「···」。
  - 会话结束或测速地址改变后，已有结果变为灰色，表示不再是当前值；重新测速后恢复颜色。同一成员在不同组里显示同一个结果。
  - 仪表盘「当前节点」显示实际出口的最近一次测速结果。
- **点击成员**：
  - Selector 组：保存为手动选择，运行中即时切换。
  - URLTest 类组（含 Fallback、LoadBalance 导入的组，D28）：成员不可手选，点击时提示「此组按延迟自动选择」；当前成员显示实际自动结果：运行中由宿主报告（内核按组自己的间隔测速后选择），未运行时不显示选中标记。
  - 运行中，Selector 组的选中标记也以宿主报告为准；仪表盘「当前节点」顺着各组的实际选择找到最终出口。
- **测速**：测试当前组全部成员，限制并发。代理链测试完整路径，不把各跳延迟相加。未连接时也可以测速，但不会接管系统流量。
- **直连模式**：显示「直连模式下直接访问目标地址」，仍允许选择。
- **「自定义」组**：包含全部自建节点、代理链，以及已保存的 Tailscale 出口（显示为「Tailscale · 设备名」）；当前出口功能按 D110 不可用，已有引用显示不可用并可清除。
- 被引用成员已失效时（如订阅更新后节点消失），该行显示「不可用」；选中它时启动或切换会报错。
- 组选择的成员不存在时，运行使用组内第一个成员，但保留已保存的手动选择；成员恢复后自动回到原选择。

### 3.3 配置

- **配置卡**：名称；来源（订阅／本地文件／「本地 · N 条代理链」）；节点数；更新时间（相对时间）；选中标记。订阅响应提供用量时显示用量条（超过 80% 为红色）和到期日，未提供则不显示。
- **点击卡片**：选中该配置。普通代理运行中会切换到新配置（D10）。当前没有选中配置时，新添加的配置自动选中（D26）。
- **卡片刷新按钮**：只在订阅卡上显示（D32）。点击后下载、校验并替换内容；失败时保留上次成功的内容，卡片显示错误和上次成功时间。
- **尚未下载**：经 Cloud 收到、但本机还没有下载内容的订阅，显示「尚未下载」和节点数「—」，并自动开始下载；选中它启动时报「订阅尚未下载」。
- **标题栏**：「全部更新」更新所有订阅；「添加」打开添加表单。
- **「自建节点」卡**：存在自建节点或代理链时显示。节点数为自建节点数；可被选中，使用默认路由（见 [CONFIG_PIPELINE §6](CONFIG_PIPELINE.md#6-编译为-sing-box-配置)）。卡片「管理」打开独立节点与代理链列表，点击具体项目进入编辑；手机使用可滚动底部弹层，桌面使用对话框。
- **空态**：没有任何配置时，显示说明和「添加」按钮。

### 3.4 编辑与删除（D17）

入口：配置卡，以及「自定义」组中的自建节点／链。移动端长按、桌面右键，弹出菜单「编辑」「删除」。配置页也可通过「自建节点」卡的「管理」列表，直接编辑具体节点或代理链；列表显示名称及节点协议／链跳数。「自建节点」汇总卡和 Tailscale 出口没有编辑／删除菜单。

| 对象 | 编辑 | 删除 |
| --- | --- | --- |
| 订阅 | 打开订阅表单并预填，可改名称、链接、自动更新；保存后立即更新一次 | 确认后删除，同时删除该配置的选择记录和成员关系；引用其节点的代理链保留，但显示「不可用」。若该配置正被运行中的普通代理使用，拒绝并提示「请先断开或切换到其他配置」 |
| 本地文件配置 | 只能改名称 | 同订阅 |
| 自建节点 | 打开节点表单并预填。秘密字段显示「已保存」，留空表示不修改 | 若被代理链使用，拒绝并列出链名；否则删除节点及其成员关系 |
| 代理链 | 打开链表单并预填 | 删除链及其成员关系 |

- 编辑时表单标题为「编辑」，隐藏「订阅／独立节点／代理链」分段；保存后对象 id 不变，回到原页面。
- 删除的对象若是某组的当前选择，该组按 §3.2 回退到第一个成员。
- 删除是真实删除，已同步对象会在其他设备上同步删除。

### 3.5 添加：订阅

分段「订阅／独立节点／代理链」，按钮「取消」「保存」。

- **字段**：
  - 订阅链接，占位「https://… 支持 sing-box / Clash 订阅」。
  - 名称，占位「自动读取」。
  - 扫描二维码（移动端，需相机权限）。
  - 从文件导入（.json／.yaml）；桌面端提示「或拖入配置文件 .json（sing-box）/ .yaml（Clash）」。
  - 自动更新开关：默认开，每 12 小时更新一次。
- **底部提示**：
  - 订阅链接：提示「保存在本机。」，手机上同时提示每 12 小时自动更新。
  - 本地文件：提示「将文件内容保存为本机配置。」；账号与同步状态在登录与同步页展示。
- **保存流程**：取得内容 → 识别格式（Clash YAML、sing-box JSON、URI 列表含 Base64） → 解析校验 → 保存 → 返回配置页。
  - 名称为空时，依次取订阅响应提供的名称、文件名；都没有则用「新订阅」。
  - 保存成功不显示由 Avalon 统一管理设置的接管提示（D29）或 Fallback／LoadBalance 转换提示（D28、D122）。无法导入的节点、组、规则、不可读内容及关闭证书验证等问题继续用提示条列出；没有可显示的警告时不显示提示条。
- **错误**：显示在表单内，表单保持打开，已填内容保留。
- **取消**：取消正在进行的下载或解析，不保存任何内容。

### 3.6 添加：独立节点

- **分享链接**：粘贴链接后点「解析」，按链接内容填入下方表单，不保存。无法识别的协议报错，不猜测为 VLESS。
- **协议菜单**：九项，每项附说明。

  | 协议 | 菜单说明 |
  | --- | --- |
  | Hysteria2 | QUIC |
  | TUIC | QUIC v5 |
  | VLESS | Reality / TLS |
  | VMess | TCP / WS |
  | Trojan | TLS |
  | Shadowsocks | AEAD / 2022 |
  | SOCKS5 | SOCKS |
  | AnyTLS | TLS |
  | HTTP | HTTP / HTTPS |

- **初始状态**：VLESS、传输 TCP、安全 Reality、端口 443；其余字段为空，占位文字只是提示。
- **字段**（括号内为占位；*为秘密字段）：

| 协议 | 服务器字段 |
| --- | --- |
| Hysteria2 | 地址（example.com）、端口（443）、密码*（必填）、混淆密码*（可选）、上行 Mbps（50）、下行 Mbps（200） |
| TUIC | 地址、端口（443）、UUID*（必填）、密码*（必填）、拥塞控制（bbr） |
| VLESS | 地址、端口（443）、UUID*（必填）、Flow（xtls-rprx-vision） |
| VMess | 地址、端口（443）、UUID*（必填）、Alter ID（0） |
| Trojan | 地址、端口（443）、密码*（必填） |
| Shadowsocks | 地址、端口（8388）、加密（2022-blake3-aes-128-gcm）、密码*（必填） |
| SOCKS5 | 地址（127.0.0.1）、端口（1080）、用户名（可选）、密码*（可选） |
| AnyTLS | 地址、端口（443）、密码*（必填）、空闲会话检查（30s） |
| HTTP | 地址、端口（8080）、用户名（可选）、密码*（可选）；TLS 即 HTTPS |

- **传输方式**：仅 VLESS／VMess／Trojan 显示，选项为 TCP／WebSocket／gRPC／HTTP2。
  - WebSocket 追加「路径（/ws）」「Host（可选）」。
  - gRPC 追加「Service（grpc）」。
  - HTTP2 追加「路径（/）」。
- **传输层安全**：
  - 选项：VLESS 为无／TLS／Reality；VMess、HTTP 为无／TLS。
  - 选 TLS 时追加 SNI；选 Reality 时追加 SNI（www.apple.com）、公钥、Short ID（可选）。
  - Trojan、Hysteria2、TUIC、AnyTLS 没有安全分段，始终显示 SNI。
  - 切换协议时保留原安全选择：原选择在新协议中不可用时显示 TLS；切回时恢复原选择。
  - SOCKS5 不显示安全分段（D84：内核 SOCKS 出站不支持 TLS）。
- **保存**：
  - 地址必填，并按协议校验；秘密字段加密保存。
  - 名称依次取：填写值 → 服务器地址 → 「新 ‹协议› 节点」。
  - 节点写入自建节点，并加入当前配置的主选择组（仅当当前配置为导入配置，主选择组定义见 [CONFIG_PIPELINE §4](CONFIG_PIPELINE.md#4-解析映射)）。
  - 保存后返回代理页「自定义」组，不自动选中，不连接。底部同样显示 §3.5 的同步提示。

### 3.7 添加：代理链

- **名称**：占位「默认用节点名拼接」；为空时用「A → B → C」。
- **链路摘要**：「N 跳 · ≈ X ms」，X 为已测各跳延迟之和，仅作估算；有跳超时则显示「超时」，未测显示「—」。
- **跳列表**：本机 → 各跳 → 目标网站。
  - 每跳显示序号、名称、角色（入口／中转／出口）、协议、延迟。
  - 支持上移、下移、移除。
  - 说明文字：「流量依次经过每一跳，最后一跳为出口，可组合不同协议。」
- **添加一跳**：可选当前配置的节点、自建节点；排除代理链和已选的跳。Tailscale 出口在完整路径验收前禁用（D110）。
- **加入代理组**：当前配置的 Selector 组多选，默认勾选主选择组。列表不含「自定义」（链总在其中）；没有可选组（如当前为「自建节点」配置）时隐藏本区域。
- **少于 2 跳**：提示「代理链至少需要 2 跳」，保存按钮置灰。
- **保存**：返回代理页「自定义」组，不自动选中，不连接。保存时只做静态校验（至少两跳、引用存在、无重复）；完整路径在使用时校验，失败在原操作中报错。
- **Tailscale 出口位置（D110）**：当前全部位置不可用；已有链在实际使用时明确报错，不能改为直连或其他出口。

### 3.8 连接与日志

- **连接**：
  - 标题显示「N 个活动连接」。每行显示主机、应用（进程）、规则、链路、↑↓ 流量。
  - 可单项关闭，标题栏可「全部关闭」。桌面端为表格。
  - 空态：未连接时「启动代理后，这里会实时显示连接」；已连接但没有连接时「所有连接已关闭」。
  - 显示与刷新：最新的连接在最上面；页面打开且代理运行时每秒刷新。应用列在 Android 上显示应用名（取自本机已安装应用），认不出时显示包名；桌面显示程序文件名；「查找进程」关闭时为空。规则列显示内核写法（如 `rule_set=geosite-cn`），走最终目标的显示「默认」。链路从规则命中的组一路写到实际出口，用用户看到的名称（如「节点选择 → 香港 01」），直连显示「DIRECT」。
- **日志**：
  - 级别筛选：全部／INFO／WARN／ERROR／DEBUG；每行显示时间、级别、消息。
  - 分享：导出当前缓冲区并脱敏后，调用系统分享。
  - 缓冲区溢出时在顶部提示「较早日志已丢弃」。
  - 显示与刷新：缓冲区最多保留 2000 行，最新的在最上面。打开页面时读一次，代理运行时每秒读新增的行；未运行时也能看到上次运行留下的日志（例如启动失败的原因）。ERROR 包含 fatal／panic，DEBUG 包含 trace。日志只包含计划日志等级允许的行（高级设置「日志等级」）。
  - 分享的内容是整个缓冲区（不受当前筛选影响），开头写明 Avalon 与内核版本和平台；每行经统一的脱敏规则处理（URL 中的凭据、token 等查询参数、认证头）。手机上调用系统分享面板，桌面上用保存对话框导出为文件。

### 3.11 分应用代理

- **模式**：白名单／黑名单分段。白名单说明「仅开启的应用走代理，其余直连。」；黑名单说明「开启的应用直连，其余走代理。」
- **列表**：顶部搜索框，下方是已安装应用（移动端）或程序（桌面端）列表，每项一个开关，切换后立即保存。
- **名单为空**（D13）：显示「未选择应用时，全部应用按规则代理。」
- 「走代理」指按当前模式和规则处理；「直连」指不经代理。
- iOS 不显示本入口（§6）。
- **列表内容**（D80、D108）：Android 列出本机所有申请了联网权限的应用（不含 Avalon 自己），每项显示名称和包名；macOS 列出「应用程序」文件夹（含系统应用和下一层子文件夹）里的应用，每项显示名称和路径。Windows 枚举开始菜单、程序登记与卸载项中的可执行程序；Linux 解析 XDG 应用目录中可见且可启动的 `.desktop` 项，按当前语言显示名称。桌面项去重并显示实际程序路径，仍可手动添加。
- **排序**：打开页面时已开启的排在最前，其后是用户安装的，最后是系统自带的，各自按名称排。页面打开期间行的位置不变，切换开关不会让行跳动；关掉的行在本次访问中保留，可以再打开。
- **搜索**：按名称、包名或路径匹配，不区分大小写；没有结果时显示「没有匹配的应用」（桌面为「程序」）。
- **已卸载的应用**（Android）：名单里的包若本机已不存在，仍然列出，名称显示包名，说明显示「未安装」，可以关掉。只含已卸载应用的名单仍算非空名单。
- **白名单里一个已安装的都没有**（Android）：代理不启动，仪表盘提示「白名单里的应用都未安装」并说明怎么改；本页顶部提示「名单里的应用都未安装」。运行中把名单改成这样时，当前会话照旧，不重载。黑名单里的应用都未安装时照常运行，没有应用被排除。
- **添加程序**（桌面，D80）：搜索框一行右侧的「添加程序」打开系统文件选择器（macOS 从「应用程序」文件夹开始，Windows 只列出 .exe），选中的程序加入名单并开启，排在列表最前。用于命令行工具和不在标准位置的程序。
- **需要「查找进程」**（桌面）：名单非空而「查找进程」关闭时，页面顶部提示「分应用代理需要开启「查找进程」。」及「开启「查找进程」，按程序应用代理规则。」，并提供「开启」；不开启则无法生成配置（[CONFIG_PIPELINE §6](CONFIG_PIPELINE.md)）。
- **读取失败**：读不到本机应用列表时提示「无法读取应用列表」，仍显示已保存的名单。
- 应用图标按 V3 画成带首字的色块，同一应用颜色固定。

### 3.12 GEO 规则集

- **规则集列表**：内置默认规则集（[CONFIG_PIPELINE §8](CONFIG_PIPELINE.md#8-规则集资源)），加上各配置引用的规则集。每项显示名称、类型（GeoSite／GeoIP／规则集）、大小、更新时间，可单独更新；未下载显示「未下载」。
- **全部更新**：更新全部规则集，进行中显示「更新中」；正在下载的行显示「下载中…」。
- **下载失败**：该行显示「下载失败」（红色），已下载的旧版本继续使用；自动更新一小时后再试。
- **更新设置**：自动更新（默认开）、更新间隔（每天／每周，默认每天）、下载方式（经代理／直连，默认经代理）。
- **经代理下载但代理未运行时**：手动更新提示「请先启动代理，或改用直连下载」；自动更新推迟到代理运行时执行。
- **首次使用**：还没下载过的规则集，第一次启动时由内核自己下载；连接成功后应用把它们保存下来，此后启动直接读本地文件。
- 说明文字：「管理和更新 GeoSite、GeoIP 及订阅引用的规则集。」
- **列表顺序与去重**：默认规则集在前，其后按配置的顺序列出各配置实际用到的规则集（DNS 规则与路由规则引用的）；同一地址只列一次，配置删除后它独有的规则集随之消失。
- **重名**：不同配置可以把同一个名称定义到不同地址。名称重复时，每一行在说明末尾显示来源主机名以便区分。
- **页首摘要**：「N 个规则集 · 每天自动更新」；间隔为每周时写「每周自动更新」，自动更新关闭时写「自动更新已关闭」。

### 3.13 Tailscale

- **顶部开关**：启用 Tailscale。实际端点需要登录并提供可信地址时打开浏览器完成 Tailscale 登录，也可使用登录行重试；状态显示真实的「已连接 · ‹tailnet›」「未启用」「需要登录」、等待状态或错误，不以开关偏好替代登录状态（D106）。
- **本机**：主机名、Tailscale IP、Tailnet，全部来自真实状态。
- **出口节点（D110）**：「不使用」为默认并可用于清除已有选择。出口设备按真实在线与出口能力展示；当前出口选用尚未完成稳定身份和失败时拒绝直连的完整验证，全部禁用，提示「出口节点功能待开放。当前可访问 Tailnet 内的设备。」（D113）。保留已有选择以供用户清除，不自动改选其他设备。
- **选项**：
  - 接受子网路由：「访问 tailnet 中其他设备公布的局域网」，默认开。
  - MagicDNS：「用设备名访问，如 home-nas」，默认开。
  - 作为出口节点：默认关；当前禁用，提示「本机出口功能待开放。」，已有开启偏好允许关闭（D110、D113）。
- **设备**：「设备 · N 台在线」，每台显示名称、系统、在线状态、IP。
- **退出 Tailscale 账户**：注销本机 Tailscale 身份。
- **固定路由**：访问 Tailscale IPv4／IPv6 地址段、`*.ts.net`、设备名及已接受的子网走 Tailscale，不受出站模式影响；不可达时失败，不回退到其他出口。MagicDNS 使用端点提供的实际名称与搜索域。
  页面说明为「通过 Tailscale 地址和设备名称访问 Tailnet 设备。」；默认出口项说明为「互联网流量使用当前网络与代理设置。」（D113）。
- Tailscale 与普通代理分别启停：关闭普通代理不影响 Tailscale，反之亦然。Tailscale 身份与 Avalon Cloud 无关，免费可用。

**同步行为**：

- 付费账户登录后自动同步：首次同步取回账号内容，并上传本机内容（安装默认值不上传）。
- 权益到期立即停止上传和下载，保留已有设备激活及云端内容，续费后原设备恢复资格（D96）；普通退出、移除或90天无有效会话仍释放同步名额。
- 之后每次保存后自动同步。
- 规则见 [CLOUD_SYNC](CLOUD_SYNC.md)。

**同步生命周期开发预览（D98）**：仅显式启用新版同步协议的开发构建展示服务端返回的备份状态、实际保留期限、重建进度及清理结果；原冻结协议预览保持上述行为。期限未知时不推算天数，不因期限已过就声称密钥已销毁。权益待核实或已停止同步时仍可查询状态，本机功能和内容保留。

- 新空间需要重建时，显示「从此设备重建」；确认说明本机该账号的当前可同步内容会作为完整备份，其他设备须等待发布，其他账号内容不上传。
- 重建者显示服务端已接收的条数及总数；分批接收不显示「已同步」。可继续重建，或确认取消尚未发布的尝试。其他设备显示等待状态，可确认「由此设备接管重建」，原尝试的未发布内容不会合并到新的尝试。
- 确认框返回时若会话、同步代次、尝试或重建者已变，原确认作废。重建不自动由其他设备接管，普通重试不自动从旧镜像重建。
- 完整备份发布后，其他设备先取得同一代次、稳定数据版本的完整结果，再原子更新本机视图。旧镜像和旧未确认请求不回灌；真实离线编辑保留至新代次裁决。本机仍可编辑和使用代理。
- 有保留的未上传或离线修改时，展示实际待合并条数；不会把所有旧本机镜像都计为修改，也不声称这些修改已经上传。
- `deleted` 显示「在线密钥已移除」，说明灾备副本从原创建时间起最多保留30天（D100）；此状态不证明所有灾备已清除。兼容状态 `destroyed` 显示「旧密钥已停用」，不作为新模式密码学销毁证明。未知状态仍报协议错误，不映射为已完成。

## 5. 文件备份（D18）

- **导出**：点「导出备份…」→ 输入两次密码（至少 8 位）→ 系统保存对话框 → 写入 `.avalonbackup` 文件。
  - 内容：全部配置（订阅定义及上次成功内容、文件导入内容）、自建节点、代理链、成员关系、手动选择、JSON 覆写、全部设置值（含仍为默认的值），以及上述内容所需的秘密。
  - 不包含：Cloud 登录状态、设备身份、Tailscale 身份、系统授权、系统代理恢复记录、日志、规则集缓存文件。
- **恢复**：点「从文件恢复…」→ 选择文件 → 输入密码 → 确认对话框「恢复会覆盖同名设置和相同对象，本机其他内容保留」→ 校验 → 一次性提交 → 提示完成。
  - 合并规则：同 ID 对象被备份覆盖；其余对象新增；本机独有对象保留；设置整体替换。
  - 本平台不适用的设置值（如 Windows 程序路径恢复到 Android）保存但不生效。
  - 密码错误或文件损坏时报错，本机数据不变。
  - 恢复不连接、不登录、不授予系统权限；已绑定 Cloud 时，恢复带来的变化按普通编辑同步。

## 6. 平台差异（D22）

| 功能 | Android | iOS | macOS | Windows | Linux |
| --- | --- | --- | --- | --- | --- |
| 启用 TUN | 显示；关闭时只运行本地混合端口 | **隐藏**，隧道始终启用 | 显示（网络扩展） | 显示；首次启用需管理员授权安装服务 | 显示；需 CAP_NET_ADMIN 授权 |
| 系统代理 | 隧道内 HTTP 代理；TUN 关闭时置灰并提示 | 隧道内 HTTP 代理 | 由网络扩展设置系统 HTTP 代理 | WinINet 系统代理 | GNOME／Unity 会话代理；其他桌面如实报不支持 |
| 分应用代理 | 按包名，由 VPN 允许／排除应用实现 | **隐藏入口** | 按程序路径 | 按程序路径 | 按程序路径 |
| 开机自动启动 | 开机后启动后台服务；同时开启自动连接则连接 | **隐藏开关**，保留说明「在系统设置中开启 VPN「按需连接」。」 | 登录项 | 登录启动 | XDG autostart |
| 静默启动、关窗保留 | 不显示 | 不显示 | 显示 | 显示 | 显示 |
| 通知栏实时速度 | 前台服务通知（另带「停止」按钮，不受此开关影响） | **隐藏** | 不显示 | 不显示 | 不显示 |
| 扫描二维码／拖入文件 | 扫码 | 扫码 | 拖入文件 | 拖入文件 | 拖入文件 |
| 连接页「应用」列 | 应用名 | 显示「—」 | 进程名 | 进程名 | 进程名 |

Android 的两个开关分别保存偏好：开启 TUN、关闭系统代理可以只接管 TUN；关闭 TUN 时系统代理显示关闭且不可操作，并显示「需要先启用 TUN」。关闭 TUN 不清除已保存的系统代理偏好，再启用 TUN 后按保存偏好应用。当前 Android 未实现脱离 VPN 隧道的系统代理模式。

macOS 的网络扩展最低支持 macOS 13，实际连接需有效团队签名、Applications 安装与系统批准；缺条件时明确报错，本地功能仍可使用（D109）。Windows／Linux 系统代理采用成功运行的真实端口；端口未知或设置失败时不显示为已接管。恢复原设置时保留用户或其他软件后来改过的代理整组；恢复失败留在应用中报告，可重试（D111）。

## 7. 桌面

- **单实例**：再次启动时聚焦已有窗口。
- **关窗**：「关闭窗口时保留」开启时隐藏到菜单栏或托盘，代理继续；关闭时，关窗即退出。
- **窗口与静默启动**：原生标题栏按钮、空白处拖动与双击执行各平台窗口操作；静默启动在本地数据与托盘检查完成前保持窗口隐藏。托盘不可用时显示窗口以便找回。
- **退出**：托盘菜单「退出」或系统退出时，停止普通代理和 Tailscale，恢复系统代理设置。
- **托盘／菜单栏菜单**（D31）：显示主窗口、启动／停止代理、出站模式（子菜单）、退出。图标反映连接状态。托盘不可用（如部分 Linux 桌面）时，关窗保留自动失效，避免窗口无法找回。
- **全局快捷键**：

  | 动作 | macOS | Windows／Linux |
  | --- | --- | --- |
  | 启动／停止代理 | ⌥⌘P | Ctrl+Alt+P |
  | 切换出站模式 | ⌥⌘M | Ctrl+Alt+M |
  | 显示主窗口 | ⌥⌘A | Ctrl+Alt+A |

  注册失败（被占用）时在基础设置的快捷键行显示「已被占用」，不改用其他组合。Windows 与 Linux X11 已接入；当前 Wayland 等不支持的会话显示「暂不支持」（D93、D108）。

## 8. 通用反馈

- **启动**：每次冷启动先播放 1 秒的品牌动画（UI_DESIGN_SYSTEM §5），同时打开本地数据；两者都完成后进入仪表盘。动画按应用的外观（深色／浅色）绘制。

- **加载**：需要等待的操作在原位置显示进度，按钮防重复点击。
- **错误**：用一句话说明原因和下一步，显示在原表单或页面顶部提示条；不弹出新的流程页。
- **系统授权**（VPN、网络扩展、管理员、相机、通知）：在实际需要时由系统请求；用户拒绝时在原位置说明影响。
- **数据库**：数据库版本比应用新时，显示「请更新 Avalon」，不读写数据；迁移失败时显示错误并保持原文件，绝不清库。
- **可用性**：全部文案走 ARB 本地化；支持系统字体缩放、读屏标签、键盘焦点（桌面）和减少动画。
