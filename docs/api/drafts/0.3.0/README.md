# 同步生命周期公开契约草案

**未发布版本**：本目录定义显式协议2开发预览，不替代现行0.2.0公开契约，也不修改0.1.1／0.2.0归档和摘要锁。候选正文由 `candidates.lock.json` 单独锁定，双端保持逐字节一致；必要修改须说明原因、兼容与迁移影响，完成双端验证后显式更新候选摘要。候选校验不表示正式发布或完整验收。客户端必须以 `AVALON_CLOUD_SYNC_VERSION=2` 明确选择，不自动降级。

[OpenAPI](cloud.openapi.yaml) 定义公开字段，[同步规范](SYNC_PROTOCOL.md) 定义可观察的生命周期、安全和兼容义务。首批账号 wire 与 payload schema 1 保持不变。

客户端按账号及代次隔离同步材料；旧未知请求和离线编辑保留于加密存储。完整下载只有在代次和数据版本稳定后才替换可见投影。重建需要用户选择本机资料，并使用固定清单、原控制请求和原上传请求恢复结果。

`cleanup.keyState=deleted` 表示在线密钥已移除；客户端保留兼容状态 `destroyed`，拒绝未知值。页面依据公开状态显示清理和最长30天的备份保留说明，不能把旧代次清理解释为当前代次失效。具体字段和保证以规范为准。

当前公开版本与本仓导航见 [公开契约入口](../../README.md)。本目录只定义公开字段、授权义务与客户端可观察保证，不保存服务端实现或运维记录。
