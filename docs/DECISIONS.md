# 决策记录

本文件记录 V3 原稿之外、或 V3 未定义而由用户确认的决策，以及关键技术取舍。用户可见行为以 [PRODUCT_SPEC](PRODUCT_SPEC.md) 为准；本文件解释「为什么」。新增或修改决策时，先在此登记，再改对应文档。

## 基线

| ID | 决策 | 理由 |
| --- | --- | --- |
| D01 | 既有 V3 界面与功能约定由 [PRODUCT_SPEC](PRODUCT_SPEC.md) 和 [UI_DESIGN_SYSTEM](UI_DESIGN_SYSTEM.md) 维护；新增或变更行为先登记决策。原始设计素材目录按用户 2026-10-23 的要求移除 | 保留当前产品与界面约束，移除原稿及演示素材；既有功能不因素材删除而变化 |
| D02 | Cloud 采用普通账号同步：HTTPS 传输、云端加密存储，不做端到端加密；授权处理可能读取同步内容。Cloud 页安全说明为「数据通过安全连接传输，并在云端加密存储。」；订阅页安全卡为「安全云同步 · 加密传输与存储」 | 用户选择，保持登录与同步简单并准确告知隐私边界 |
| D03 | 唯一运行引擎为官方 sing-box，固定为 v1.14.2（commit `af6e64c3b69e6132ebaee0e1a3d24e93903f6709`）；Clash／Mihomo 只作导入格式 | 单引擎降低复杂度 |
| D04 | Avalon 自有代码 AGPL-3.0-only；本地功能全部免费；Cloud 月付 ¥8、年付 ¥68（默认年付），最多 10 台设备 | V3 与用户方向 |

## 产品行为

| ID | 决策 | 理由 |
| --- | --- | --- |
| D10 | 后台变化自动生效：普通代理运行中，当前配置的生效内容变化（订阅更新、Cloud 接收、JSON 覆写、设置、删除成员等）在 1 秒防抖后自动重载；计划内容未变则跳过；重载失败保留旧会话并在仪表盘报错。组选择与模式变化即时切换，不重载。TUN／系统代理开关立即反馈并排队应用，不等待后台防抖；平台处理方式见 RUNTIME_HOST。非当前配置的变化不影响运行 | V3「一处修改，处处生效」且没有「应用」按钮；开关响应按用户要求与已实现的交互保持一致 |
| D11 | 同步冲突按记录 LWW：比较编辑时间 `editedAt`，由服务端裁决（`editedAt` 截断为不晚于服务端当前时间）。落败的本地版本丢弃，写脱敏调试日志。不提供冲突界面 | 数据小、单用户，结果可预期 |
| D12 | 「节点选择记录」按 V3 同步。接收设备若正在运行同一配置，立即切换到该成员 | V3 可见合同；偏好与实际保持一致。若用户反馈打扰，可改为仅更新偏好（单一开关） |
| D13 | 分应用初始名单为空。空名单表示不启用分应用，全部应用按路由规则处理；白名单／黑名单只在名单非空时生效。名单为空时页面显示提示 | V3 默认白名单＋空名单会让所有流量直连 |
| D14 | 设备名额：设备在付费账号上激活同步时占用名额；退出登录、被移除，或会话 90 天未刷新时释放。第 11 台设备可登录但不同步，Cloud 页提示移除设备。设备列表允许移除非本机设备 | V3 列表只读，满额后无出路 |
| D15 | 权益到期后停止同步（推送与拉取）；云端数据保留至删除账号；续费后按 D11 合并 | 实现最简单，不丢数据 |
| D16 | 新增「删除账号」：位于 Cloud 页底部，需二次确认。删除云端数据并撤销全部会话，本地数据保留；提示用户到购买渠道取消订阅；另提供网页删除入口 | App Store 审核指南 5.1.1(v) 与 Google Play 账号删除政策 |
| D17 | 新增最小管理入口：配置卡，以及「自定义」组中的自建节点／链，支持长按（移动端）或右键（桌面）菜单「编辑」「删除」。配置页「自建节点」卡另提供「管理」，列出独立节点与代理链，点击具体项目编辑；汇总卡本身不可编辑或删除，主点击仍选中配置。编辑复用添加表单并预填。规则见 [PRODUCT_SPEC §3.4](PRODUCT_SPEC.md#34-编辑与删除d17) | 否则无法修正错误或清理失效订阅；用户于 2026-10-20 要求在配置页支持独立节点与代理链的编辑，补齐汇总卡到具体项目的入口 |
| D18 | 文件备份：导出时输入两次密码；用 Argon2id 派生密钥，XChaCha20-Poly1305 加密整个文件；恢复时输入密码。恢复按对象 ID 合并：备份对象覆盖同 ID 本地对象，其余新增，本地独有对象保留；设置整体替换为备份值（本平台不适用的值保存但不生效）。恢复前确认；恢复不登录、不连接 | 秘密不能明文，又要能跨设备恢复 |
| D19 | JSON 覆写作用于所有导入配置（订阅 URL 和文件导入），不作用于「自建节点」；只允许 [CONFIG_PIPELINE §5](CONFIG_PIPELINE.md#5-json-覆写) 登记的键，其他键在保存时报错 | 语义明确、可校验 |
| D20 | 「恢复默认设置」把高级设置页各项恢复为默认值；保留 JSON 覆写和 Clash API 密钥；执行前确认 | 不误删用户内容 |
| D21 | 语言：首版提供简体中文和 English；初始值取系统语言，不支持时用简体中文 | 原稿只画了语言行 |
| D22 | 平台差异按能力隐藏控件，不显示必然失败的开关。规则见 [PRODUCT_SPEC §6](PRODUCT_SPEC.md#6-平台差异d22) | iOS 消费级应用无法实现按应用接管（需要 MDM） |
| D23 | Linux 无 Secret Service 时，主密钥改存权限 0600 的本地文件，关于页显示「安全存储：本地文件」 | 否则精简桌面环境无法保存任何密码 |
| D24 | 关于页致谢为「致谢 sing-box 与开源社区」；许可显示 AGPL-3.0（内核 GPL-3.0-or-later）；版本取实际构建信息 | 准确展示实际使用的项目、许可和版本 |
| D25 | 「规则与覆写」同步范围限于 JSON 覆写和 GEO 更新设置。DNS、TUN、端口、LAN、路由开关、Clash API、分应用、启动、外观、语言属于设备设置，不同步，但包含在文件备份中 | 网络环境因设备而异 |
| D26 | 当前没有选中配置时，新添加的配置自动成为选中项（不连接）；已有选中配置时不改变选择 | 首次使用少一步 |
| D27 | 首次同步合并时，与云端订阅 URL 相同的本地订阅并入云端记录（改用云端 ID） | 避免第二台设备出现重复卡片 |
| D28 | Clash 的 Fallback／LoadBalance 组导入为 sing-box `urltest`；界面保留原类型名，转换信息留在内部导入记录，保存成功不显示此类提示（D122）。URLTest 类组的成员不可手选 | sing-box 主线没有对应出站类型（按固定内核复核） |
| D29 | DNS 统一由设置页决定。导入配置中的 DNS、入站、日志、experimental 等字段被忽略，信息留在内部导入记录，保存成功不显示此类提示（D122）；高级用户可用 JSON 覆写追加 DNS 服务器和规则 | 单一事实源 |
| D122 | 成功导入时不展示 `ignoredSection` 与 `approximatedGroupType` 两类例行提示；过滤后没有其他警告时不显示警告条。其他导入问题及错误继续展示，内部记录、解析结果与运行配置保持原规则 | 用户于 2026-10-21 明确要求移除设置接管与 Fallback 转换提示，认为这些提示没有意义；只调整展示，保留现有数据兼容性 |
| D30 | 外部面板（Clash API）对模式或组选择的修改视为用户操作，写回本地偏好（并按 D12 同步） | 避免偏好与实际长期不一致 |
| D31 | 桌面托盘／菜单栏菜单：显示主窗口、启动／停止代理、出站模式（子菜单）、退出 | 原稿未画，需要最小可用菜单 |
| D32 | 订阅卡显示刷新按钮；本地文件卡和「自建节点」卡不显示刷新按钮（无远端来源） | 避免无意义操作 |

## 技术

| ID | 决策 | 理由 |
| --- | --- | --- |
| D120 | 大配置的代理页使用按行构建的 sliver 列表与整组连续背景，保留原有圆角、分隔线、按压及转场参数；`MemberCatalog` 在单个内容快照内建立首匹配索引并缓存完整根引用的可用性结果，递归 detour 与链跳校验仍独立执行。缓存随快照重建，不跨配置或内容版本复用。绘制层候选必须用同机反向对比验证，无稳定收益或影响视觉的方案不保留 | 用户于 2026-10-21 要求继续优化真机性能；大量节点时整组布局及跨组重复线性查询造成明显 UI 长帧，需要减少实际工作量并保持现有动画质量 |
| D121 | Android 根标签切页保留原有淡入、0.985→1 缩放、曲线、时长和底栏材质；动画期间使用 Flutter 自带缩放滤镜与固定重绘边界，复用 1 倍输入，结束后撤去滤镜。真实内容变化仍正常重绘，不保存页面截图。仅在 Android 根标签启用，桌面、iOS 和弹层原路径保持；不引入自定义渲染层。运动中文字有轻微采样差异，以参考画布及真机核验 | 用户于 2026-10-21 要求在尽可能保留动画质量的前提下继续优化。连续缩放下逐帧创建的缓存只能使用一次；同机候选对照中固定输入复用使绘制耗时明显下降。1.5／2 倍及高质量采样未带来一致的文字质量收益，且恢复原始绘制时有字形跳变，因此选用 1 倍低阶采样 |
| D119 | 按核心故障风险精简抽象与自动化测试：删除无独立职责的转发层、不可达分支和重复实现；移除只验证外观、固定文案／常量、对象自身相等与重复模拟的低价值测试及无引用夹具。自动化重点保留真实配置导入／编译、编辑保存、运行重载与错误恢复、本地数据与密钥／备份安全、认证与同步一致性、宿主及网络权限边界、发行签名和版本一致性；保留包边界架构守卫。每项简化核对调用关系与剩余核心回归，代表性故障变异须能使保留测试失败，恢复后再通过；不以全绿或测试数量代替消融证据。原有视觉效果与交互保持，视觉参考用于按需人工复测 | 用户于 2026-10-20 明确要求全项目消融、去除不必要抽象与无／低价值测试，只保留极重要核心功能测试；减少维护负担，同时继续保护不可丢数据、不可错误直连及真实发行等关键约束 |
| D40 | 客户端为一个 Dart pub workspace，三个包：`app`（应用：feature-first MVVM、Riverpod 3、Drift、go_router）、`av_core`（纯 Dart：domain 与 pipeline，不依赖 Flutter）、`av_design`（设计系统）。原生宿主拥有数据平面。2026-10-09 由单包修订 | 只按「是否纯 Dart、是否稳定」切分，不按技术层拆包；纯度由包依赖在编译期保证 |
| D41 | Avalon Core Bridge（Go）包装 sing-box 库，提供统一的命令与观察 API。移动端用 gomobile 嵌入宿主，桌面端为 helper 进程；Flutter 进程不加载内核 | 五平台一致的控制面；Tailscale 状态等需在 Go 侧暴露 |
| D42 | 运行控制只用三个标识：`requestId`（命令幂等与超时查询）、`sessionId`（宿主会话）、`planHash`（计划内容） | 原设计的标识过多，早于引擎验证 |
| D43 | 运行观察首版采用页面可见时 1 秒轮询；日志按序号增量读取；不建事件流 | 简单，够用 |
| D44 | 同步协议：记录级 revision、LWW、幂等 `mutationId`、批量 push（每批 ≤100 条）、游标 pull（cursor=0 即全量）、永久墓碑 | 原协议与「保持简单」相悖 |
| D45 | 客户端只依赖公开的 Cloud 接口契约，不依赖服务端内部技术选型或实现 | 服务端实现不属于本仓库的维护范围（D91、D103） |
| D46 | 规则集由应用管理缓存（GEO 页可显示大小和时间）。缺缓存时编译为 remote 规则集，由内核按所选下载方式首次取得；运行中「经代理」下载经 Bridge 指定出站 | 解决「经代理」首次下载的先有鸡还是先有蛋问题 |
| D47 | 秘密存储：主密钥放系统安全存储；秘密用 XChaCha20-Poly1305 加密后存入同一 Drift 数据库，与内容在同一事务提交 | 避免跨存储一致性问题；绕开 Windows 凭据大小限制 |
| D72 | 每个页面分为纯展示的 `XxxView`（只接收页面状态与回调，不碰 Riverpod）和接上 ViewModel 的 `XxxScreen`。开发画廊与参考画布用夹具渲染 View，位于 `app/gallery/` 等开发目录（`lib/` 之外，发布构建不含）；V3 复刻页作对照基准，逐页被真实 View 取代。核心交互回归按 D119 保留 | 视觉复测覆盖真正发布的页面；展示与状态分离，便于维护 |
| D73 | 传输分为两类：Android／Apple 经原生平台通道访问宿主（系统 VPN 接口须原生）；Windows／Linux 由 Dart 经受保护的本地 IPC 直连 helper（Windows 命名管道见 D124），不写 C++／GObject 平台通道。所有宿主调用异步；通道命令形态由 D85 更新为通用 JSON | 省掉两套原生实现；iOS 与扩展通信本身是异步的，Android 绑定服务不应阻塞主线程 |
| D74 | 宿主协议带版本：`capabilities` 返回 `protocolVersion`；与应用不匹配时不发送计划，提示更新宿主（Windows 服务、macOS 系统扩展会跨应用升级继续运行） | 避免新应用把旧宿主看不懂的计划发过去 |
| D75 | 后台执行：Android 定时更新由 WorkManager 调用无界面 Dart 入口，与前台界面共用同一个 Drift 后台 isolate（经 IsolateNameServer 登记），更新后经 HostGateway 交付新计划；iOS 后台刷新在主引擎内运行。宿主一侧发起的启停（系统 VPN 开关、通知栏停止、按需连接）以宿主为准，RuntimeCoordinator 只同步意图，不自动重连 | `:vpn` 进程没有 Dart，不能解析和编译；多引擎各自开库会导致界面不刷新与并发写 |
| D76 | 依赖规则由包边界与架构测试强制执行（`app/test/architecture_test.dart` 等）；严格分析（strict-casts／inference／raw-types）；mise 固定 Flutter 3.44.4 | 规则不靠口头约定；工具链可复现 |
| D117 | V2 官网为 `https://getavalon.app`；应用标识统一为 `app.getavalon.avalon`，Apple Packet Tunnel 与 App Group 同步使用该命名空间，更新发行 manifest 与商店链接跟随新标识。既有安装不做跨应用沙箱／密钥迁移，此前 V2 开发安装可用当前格式的密码备份迁移，V1 跨代备份兼容另行验收；保留 V1 归档与既有发行 | 用户于 2026-10-20 要求为 V2 CI 更新官网、包名和 README；反向域名与自有官网保持一致，不能把换应用标识描述成原位升级 |
| D118 | V2 CI 从当前源码独立建立：`main` 推送、面向 `main` 的 PR 及手动检查只运行格式、分析、测试与契约等检查；使用 `v` 前缀和 `.github/release_template.md` 发行说明模板，唯一发行路径为与 `app/pubspec.yaml` 一致的三段版本标签 `v<version>`（如 `v2.0.0`）。发行流程复用同一检查并构建各平台，通过后创建 GitHub Release；模板保留下载统计、平台表格与徽标，变更列表来自当前 V2 历史，下载链接只列实际发布制品。Android 三 ABI 正式 APK 必须具备完整发行签名并通过签名、标识与版本核对，缺凭据即停止，不回退到 unsigned 或调试签名。当前 Release 仅包含符合发行条件的 Android 包、更新 manifest、源码与许可信息及校验和；其余平台构建只存 Actions 验证制品，待相应验收后纳入发行。不覆盖既有 Release，不自动创建或推送标签 | 用户于 2026-10-20 要求配置 V2 GitHub Actions，明确 main 只测试、只有 tag 发布，并纠正为使用 V1 的 v 前缀及 Release Notes 模板，随后明确只需正式版本发行流程；保持单 sing-box 引擎和真实入口，区分构建验证与可安装发行，保留 V1 归档与发行 |
| D116 | 当前 Flutter pin 下，Android 12 及以上的 MT6855（PowerVR BXM）使用 Skia 渲染，其余设备继续由 Flutter 选择后端；显式调试参数可覆盖，升级 Flutter 时重新核对该兼容项。保留既有曲线、时长、缩放与模糊效果 | 2026-10-20 真机同包对比重现 Impeller Vulkan 绘制超时，OpenGLES 仍有明显超时，Skia 稳定改善；[Flutter 官方修复](https://github.com/flutter/flutter/pull/191903)也将 B 系列 PowerVR 排除出 Vulkan。限制到已验证芯片，避免将单机结果推广到全部 Android |
