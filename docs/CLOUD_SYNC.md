# 客户端账号与同步

本文维护客户端的账号、权益、设备与同步规则。请求、响应和同步语义以 [OpenAPI](api/cloud.openapi.yaml) 及其引用的 [SYNC_PROTOCOL](api/SYNC_PROTOCOL.md) 为准；用户可见行为见 [PRODUCT_SPEC §3.14](PRODUCT_SPEC.md#314-avalon-cloud订阅与登录)，实现范围与剩余验收见 [Cloud 状态](STATUS.md#cloud)。

## 1. 范围

- 账号功能为客户端提供登录、权益和设备管理，以及用户选择内容的同步（D02、D04）。
- 未登录、免费账户、离线或权益到期时，本地功能照常。退出登录与删除账号都保留本机内容和代理凭据。
- 同步使用 HTTPS；同步内容不采用端到端加密，服务提供方可在处理授权请求时读取内容（D02）。客户端应如实展示这一边界，不上传本机主密钥，不要求用户保管云端密钥。
- 本仓库不记录服务端内部架构、数据存储、加密实现或运维方案。

## 2. 公开接口约束

- [docs/api/cloud.openapi.yaml](api/cloud.openapi.yaml) 是客户端兼容的公开接口来源；不可变归档和 SHA 锁防止接口被无意改写。
- 客户端必须严格校验响应的类型、版本、字段和引用，不根据错误消息文本猜测行为，不静默忽略未知记录或清理状态。
- 接口变更须说明必要性、兼容影响与迁移路径，并使用新的经审核版本；本文件不另行定义接口。
- 默认采用现行协议1。生命周期预览必须显式选择 [0.3.0 草案](api/drafts/0.3.0/README.md) 的协议2，不自动降级，也不覆盖冻结协议1。
- 协议2及认证／购买候选的完整文件由 [candidates.lock.json](api/candidates.lock.json) 固定，纳入普通契约检查及双端一致性验证。更新须记录必要性、兼容影响与迁移方案，经评审和双端验证后显式更新摘要；候选锁不代表正式发布（D114）。

## 3. 认证与设备

- **邮箱登录**：保存返回的 `challengeId` 和 `expiresAt`，按公开响应区分错误验证码、过期、次数耗尽和已使用。重发等待 `429 RATE_LIMITED` 的 `Retry-After`；验证码有效期不作为重发冷却。验证码不得写入日志。
- **Apple／Google 登录**：按产品规格选择原生登录或系统浏览器。客户端不内置 OAuth client secret，不使用嵌入式 WebView。相关实现范围以 [Cloud 状态](STATUS.md#cloud) 为准。
- **安装身份**：首次启动生成 `installationId`，登录时提交安装身份、设备名和系统；它不进入备份，也不能证明账号权限。
- **活动会话**：客户端只持有一个活动账号／会话，换账号先退出并保存原会话的待撤销证明。令牌与证明只存于本机加密秘密表。
- **刷新**：同一会话的并发刷新合并为一次。发送前通过事务抢占持久化的 `refreshUncertain` 标记；成功后原子保存新令牌并清除标记。超时、网络中断、无效成功响应或进程中断后要求重新登录，不自动重发旧 refresh token。资料更新不能覆盖这一标记或最新令牌。
- **退出**：在一个本机事务中保存加密待撤销证明及其原期限，清除活动令牌，停止同步并保留本机内容。离线补撤销使用 proof-only 请求，不附新账号的 Bearer。
- **补撤销结果**：204 表示已确认撤销；明确的 `401 AUTH_REQUIRED` 可清理失效待办，但须显示撤销未确认。网络错误、未知或畸形 401 保留待办。客户端不只凭本机时钟丢弃证明；删除待办时核对原会话和 token，避免迟到回包清除新证明。

## 4. 权益与购买

- 客户端根据公开资料中的方案、渠道、到期时间与状态显示权益，不用自造的 `isPro` 布尔值代替状态。取消续费但尚未到期仍显示有效；免费账号不开放同步。
- Apple／Google 渠道显示商店返回的本地化价格；网页渠道显示公开方案接口返回的价格。购买与恢复的接入范围见 [Cloud 状态](STATUS.md#cloud)。
- 恢复购买若返回 `PURCHASE_OWNED_BY_OTHER`，显示「该购买已绑定其他账号」。
- 发布购买结果前核对它仍属于当前登录账号；换账号后到达的旧结果丢弃。

## 5. 同步数据

| 客户端内容 | 记录类型 | 同步范围 |
| --- | --- | --- |
| 订阅与文件配置 | `configuration` | 用户配置元数据；订阅来源与请求头；文件内容及其秘密 |
| 自建节点 | `node` | 节点参数、秘密与组成员关系 |
| 代理链 | `chain` | 链跳引用与组成员关系 |
| 规则与覆写 | `policy` | 用户修改过的 JSON 覆写与 GEO 更新设置 |
| 节点选择 | `selection` | 用户手动选择的成员引用 |

不同步订阅下载内容、用量、刷新时间、设备设置、规则集缓存、Tailscale 身份、测速结果或运行状态。完整 payload、标识与版本规则引用公开契约，不在此复制。

- 「自建节点」配置在各设备的 id 都是 `self`。
- 引用以 id 解释，名称只供显示。尚未到达或已失效的引用保留，界面显示「不可用」，不按名称自动重绑。
- 未修改的默认 policy 和自动选择不产生上传。
- 远端记录、未解析引用、原请求和同步档案都可能含秘密，持久化只使用客户端加密存储；秘密孤儿清理必须保留这些材料的引用。

## 6. 同步协议

客户端按公开契约调用激活、上传和下载接口，并执行以下本机约束：

- 激活前不执行普通上传或下载；按响应显示权益、设备名额或更新要求。
- 上传按条数与字节预算拆批。确认的连续前缀完成后继续上传未确认部分，不能把成功 HTTP 状态当成整批确认。
- 结果不确定时保留原 mutationId 和原正文，禁止把旧请求改成新内容后重发；请求正文只保存在加密 outbox。
- 格式、版本、配额或大小错误保留待办并显示原因，不删除内容或截断字段。
- 采用公开协议的严格时间 LWW。收到 `superseded` 后按已观察到的 winner 更新，不能因本机时间偏差无限重发同一旧 mutation。
- 下载逐页校验，记录写入和 cursor 推进在同一个本机事务中完成；版本或任一记录无效时整页拒绝，不推进 cursor。
- 删除按明确墓碑处理，不用空秘密或解密失败代替删除。

## 7. 客户端同步引擎

同步实现由严格 DTO、HTTP 客户端、加密 Repository 和串行 `SyncEngine` 组成；页面不拥有 worker，也不直接写同步表。本机 schema、加密存储和备份排除项见 [DATA_MODEL](DATA_MODEL.md)，正式入口与开发预览的范围见 [Cloud 状态](STATUS.md#cloud)。

**本地编辑**：在业务事务内同时更新 `dirty`、编辑时间、删除状态和新 mutationId。对象未绑定账号且当前账号已激活时，按既定首次合并流程建立归属；其他账号对象不上传。订阅刷新、用量、缓存和自动选择不是用户编辑。

**Worker**：单例串行执行。本地提交后 2 秒防抖，启动、回到前台、前台每 5 分钟和「立即同步」触发。先下载再上传；HTTP 在数据库事务之外执行，网络失败保留 dirty 并指数退避，最长间隔 5 分钟。退出、换账号、撤销或销毁 worker 后旧身份失效，所有回包提交前重新核对账号、会话和本机 worker 身份。`lastSyncAt` 只在约定工作确认完成后更新。

- 下载时，本地尚未确认的更新保留，远端镜像和 revision 仍记录；否则按远端结果原子投影。
- 跨页缺失引用随完整记录加密保留，不造假对象、不按名字替换、不回退直连；目标到达后重新投影，不改用户编辑时间。
- `applied` 只在当前 mutationId 未变时清除 dirty；不能倒退已观察到的 revision。
- `superseded` 只处理对应的原请求，新编辑已生成新 ID 时不能覆盖新编辑或清除新 dirty。
- 首次激活先完整下载。未绑定订阅只按原 URL 字符串完全相同一对一合并，并在同一事务中改写身份、成员、链跳、选择引用及待办（D27）；已发送请求仍按原身份确认。不按名称或忽略 token 后的 URL 合并，也不继承本机私网访问许可。
- policy／selection 按账号保存独立内容，不让全局单行混合多个账号归属。

**远端变化**：Repository 流驱动界面和 RuntimeCoordinator。新订阅或来源变化立即交给 SubscriptionUpdater，下载完成前显示「尚未下载」；URL 或请求头变化与旧内容、旧授权清除在同一事务中提交。远端删除保留仍被使用的引用并显示「不可用」；若当前运行配置被删，当前会话继续旧计划，并提示用户处理（D10、D12）。

**来源限制**：远端来源和 source generation 持久保存，贯穿订阅、provider、规则集、覆写和编译；前台、重启、手动刷新及 Android 无界面更新使用相同限制，不自动继承本机／私网访问许可。下载检查实际 IP 和各次重定向，跨 origin 移除来源凭据。宿主不能保证最终连接地址限制时，涉及受限远端对象的计划拒绝启动或测速并保留已有计划，不能仅因同步保存成功便允许代理运行。

## 8. 设备名额

- 设备页显示公开账号资料中的设备列表和激活状态；每个账号最多 10 台同步设备（D14）。
- 激活遇到 `409 DEVICE_LIMIT` 时显示「设备数已达上限」；账号权益失效停止同步，不影响本机使用。
- 移除设备按公开接口请求处理；当前会话失效后转为退出状态，本机数据保留。
- 同设备重登录、退出及权益恢复的状态按公开响应更新，不用安装身份或本机缓存自行授予激活资格。

## 9. API 客户端

冻结接口包含邮箱登录、刷新、退出、账号资料、删除账号、移除设备和三个同步操作。路径、HTTP 状态、请求／响应字段与错误码直接引用 [OpenAPI](api/cloud.openapi.yaml)。尚未冻结的登录与购买操作按 [产品需求](PRODUCT_SPEC.md#314-avalon-cloud订阅与登录) 和 [Cloud 状态](STATUS.md#cloud) 跟踪，不写入既有 wire。

客户端只根据结构化 `code`／`reason` 分支，不解析 `message`。未知错误保留可恢复材料并显示操作失败；不把未知授权错误当成已退出、同步成功或已删除。

## 10. 生命周期兼容

显式协议2预览读取公开的资料状态、同步代次与完整下载 head，不自动迁移冻结协议1（D98）：

- 保留旧 cursor 和未知请求；只有公开响应明确证明同账号的旧空间继承或退休时才迁移，不由代次变化推断本机内容应被删除。
- 到期时只读取允许公开的状态，不尝试绕过资格获取同步内容。
- 用户选择本机起点后，固定原编辑时间、清单和 mutation。暂存确认只显示上传进度，完整发布后才建立普通镜像。
- 控制结果不确定时重放加密保存的原请求；迟到回执不能授予当前重建权。
- 完整下载须确认同一代次与稳定 head 全部收齐，才原子切换投影。失败或半份下载保留本机可见内容。
- 当前重建设备显式绑定所选本机内容；其他设备不自动回灌旧镜像或上传独立本机资料。

## 11. 删除账号与清理状态

- 删除账号按产品要求两次确认并提交公开请求；只有确认成功后才解除该账号绑定。
- 本机解绑先在事务中加密归档活动文档、未知请求和暂存材料，再清除活动同步状态。本机内容、凭据、来源限制和其他账号保持；归档不作为自动上传来源。
- 普通退出继续保留原账号待同步材料；再次登录该账号可继续处理。切换账号不上传原账号内容。
- 协议2明确接受 `cleanup.keyState=deleted` 与兼容的 `destroyed`，未知状态拒绝。`deleted` 文案只表示相关在线密钥已移除，不表示所有副本清除或密码学销毁。公开的最长 30 天保留说明从原始创建时间计算，不因重复打包延长（D100）。
- 不用新状态改写旧协议保证，不把本机测试结果当成全部副本已清理的证明。

## 12. 客户端安全

- 账号与同步请求使用 HTTPS；本机联调例外只能由明确的开发配置启用，不进入正式构建。
- 公开客户端没有可用于证明权限的嵌入密钥；包名、installationId 和契约 SHA 都不是授权凭据。
- 不把令牌、验证码、同步正文、认证 URL 或节点秘密写入日志、普通缓存或临时文件。
- 本机主密钥和同步代次分别处理：本机缺钥时保留密文并停止，不自动换钥、清库或把空秘密上传。
- 网络、账号或同步失败不阻塞本地使用，不切换节点或降为直连。安全约束见 [SECURITY](SECURITY.md)，实现与验收范围见 [Cloud 状态](STATUS.md#cloud)。
