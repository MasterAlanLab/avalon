Avalon is a proxy client for mobile and desktop. Manage subscriptions, nodes, and proxy chains in one place, view connection information, and back up your local configurations. All local features are free.

## Get Avalon

[Official website](https://getavalon.app)

Avalon V2 is in development; V2 downloads are not available yet. Existing releases are V1. For V1 source and downloads, see the [V1 archive](https://github.com/MasterAlanLab/avalon/tree/legacy/v1).

## Features

- **Subscriptions and nodes:** Import links, files, or QR codes; manage subscriptions, update their contents, and edit standalone nodes.
- **Proxy chains:** Combine multiple nodes into a connection path and test node or full-chain latency.
- **Flexible routing:** Switch between rule, global, and direct modes.
- **Connection information:** View connections, logs, traffic, latency, and exit IP addresses.
- **Local data and backups:** Keep configurations on your device, store proxy credentials encrypted, and create or restore password-protected backups.
- **Appearance and language:** Light and dark themes, with English and Simplified Chinese interfaces.

## Platforms

Designed for Android, iOS, macOS, Windows, and Linux. Feature availability varies by platform.
